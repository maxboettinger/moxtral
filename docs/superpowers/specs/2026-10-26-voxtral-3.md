# moxtral 0.5.0: Voxtral 3 support (spec)

Date: 2026-10-26. Decision by Max: default model switches to `voxtral-mini-transcribe-3`.

## 1. Intent

Make `moxtral transcribe` usable with Mistral's Voxtral 3 transcription models (released 2026-10-20) and
keep Voxtral 2 working. The `vlog` pipeline (life-analysis) depends on `--language de --timestamps segment`
on `voxtral-small-transcribe-3`, which the current 0.4.x refuses with a V2-only rule.

## 2. API facts (docs.mistral.ai, verified live 2026-10-26)

| | Voxtral 2 (`voxtral-mini-latest`, `voxtral-mini-2602`, `voxtral-mini-transcribe-2507`, `voxtral-small-*-2507`) | Voxtral 3 (`voxtral-mini-transcribe-3*`, `voxtral-small-transcribe-3*`, `voxtral-*-transcribe-latest`) |
|---|---|---|
| `language` + `timestamp_granularities` | mutually exclusive | allowed together |
| `word` timestamps | supported | HTTP 400 |
| `diarize` | optional | requires `timestamp_granularities=segment` (422 otherwise) |
| `context_bias` | supported | supported (shares the 65k context) |
| Price | $0.003/min | mini $0.0035/min, small $0.004/min |

Response shape is unchanged (`text`, `segments[]`, `usage.prompt_audio_seconds`, `language: null`).
The installed SDK (`mistralai` 2.6.0) `audio.transcriptions.complete` takes: model, file, file_url,
file_id, language, temperature, diarize, context_bias, timestamp_granularities, retries, timeout_ms.
No `return_language` parameter exists in this SDK version; it is out of scope.

## 3. Behaviour

1. `model_family(model) -> "v2" | "v3" | "unknown"` by prefix table (section 2). Unknown models get no
   client-side rules; the API decides.
2. Validation in `build_transcription_request`:
   - v2: `--language` with `--timestamps` -> `InputError("--language cannot be combined with --timestamps on Voxtral 2 models.")` (existing rule, now scoped).
   - v3: `--timestamps word` -> `InputError("--timestamps word is not supported by Voxtral 3 models; use segment.")`.
   - v3: `--diarize` without `segment` -> `segment` is added automatically (recorded in request metadata, so the dedupe fingerprint reflects it).
   - unknown: no family rules.
3. Default `--model` becomes `voxtral-mini-transcribe-3`. Existing dedupe entries for `voxtral-mini-latest`
   stay valid for explicit `--model voxtral-mini-latest` runs.
4. Docs: README option table and note, `agent_guide.md` transcribe options, CHANGELOG `0.5.0` entry
   under "Changed (breaking)" (default model) and "Added" (Voxtral 3 rules). JSON schema unchanged
   (`schema_version` stays 1). Version bump to 0.5.0 in `pyproject.toml` via `uv version 0.5.0`.

## 4. Validation

- `uv run pytest -q`, `uv run ruff check .`, `uv run pyright` green.
- Live (Max, after release): `moxtral transcribe --language de --timestamps segment clip.flac` on the
  default model returns segments.

## 5. Out of scope

Realtime/streaming, `file_id` uploads, `return_language`, speaker reference clips, chat completions.
